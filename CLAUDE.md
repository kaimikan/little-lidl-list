# CLAUDE.md

Guidance for Claude Code when working in this repository.

## This repository is PUBLIC

Anything committed here is visible to anyone, effectively forever: forks,
mirrors, and archive crawlers survive later privatization. Before every commit:

- No secrets: no tokens, API keys, passwords, pairing codes, or private URLs,
  not even inside screenshots, QR codes, or example output.
- No personal data: no addresses, phone numbers, order numbers, or other
  people's names and handles without their consent.
- Never name or identify the author's employer or its partner companies, in
  text, photos, Wi-Fi network names, banners, or file metadata.
- Audit every new image before committing: check backgrounds, screens, labels,
  and reflections for any of the above.
- Public-facing prose (README, docs, site pages) goes through the humanizer
  skill: no em dashes, no AI-writing tells.
- New vendored assets keep their license and attribution files.
